# Zenith Soft Plugin Manager

**A free collection of tools for Rhino 7.**

Zenith Soft Plugin Manager brings together a growing collection of practical plugins designed to extend Rhino’s capabilities and make modeling, mesh processing, design, and fabrication workflows easier and more efficient.

The goal is simple: provide useful, accessible tools for everyday design and production tasks — all in one place.

## Plugin Collection

### Modeling & Mesh Tools

- **Voxel Remesher** – Remesh and optimize 3D meshes.
- **Smooth** – Smooth mesh surfaces and reduce unwanted irregularities.
- **Fill Holes** – Repair open boundaries and fill holes in meshes.
- **Retopology** – Create clean quad-based topology.
- **Sculpt** – Tools for sculpting and editing 3D meshes.
- **Organic Support** – Generate organic support structures.
- **Outline** – Extract outlines and profiles from geometry.
- **Rasterizer** – Convert raster images into vector-based geometry and patterns.

### Design & Workflow Tools

- **Wood Stock** – Tools for woodworking stock preparation.
- **Viewport Plus** – Additional viewport navigation and control tools.

### Nesting

A powerful plugin featuring four dedicated workspaces for different production workflows:

- **3D Printing** – Arrange parts for 3D printing.
- **2D Sheet Nesting** – Arrange parts on flat sheets.
- **Timber Bandsaw** – Workspace for timber bandsaw cutting layouts.
- **Saw** – Workspace for saw-based cutting workflows.

### Currently in Development

The following plugins are under development:

- **Parametrics**
- **SheetMetal**
- **4Axis Prep**

## Compatibility & Availability

- **Supported Software:** Rhinoceros 3D – Rhino 7
- **Price:** Completely free

Zenith Soft Plugin Manager is an ongoing project. New tools, improvements, and features will be introduced over time.
